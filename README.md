# 小岚 LoRA 阵列 · XiaoLanLoraArray

**一个只把 LoRA 加载到 `MODEL`、完全不碰 CLIP 的 ComfyUI LoRA 栈加载器。**

一行一个 LoRA，权重和触发词就地改；行数不限，触发词自动合并成一个端口。

## 它解决什么问题

在 ComfyUI 里叠 5 个 LoRA，通常要拖 5 个 `LoraLoader`，再想办法把 5 个触发词凑进提示词里：要么手抄（容易漏），要么每个 LoRA 再配一套 `CLIP Text Encode`。改一个权重要在节点堆里点来点去，想临时关掉某一个还得先把线拔了。

这个节点把它压成**一个节点、N 行**：

| 原来的做法                    | 用小岚lora阵列                           |
| ------------------------ | ----------------------------------- |
| 5 × `LoraLoader` + 手抄触发词 | 1 个节点、5 行                           |
| 改权重要点开每个节点               | 行内 `－` / `＋`，或按住权重区左右拖动微调           |
| 临时关掉某个 LoRA 要断线再接        | 行首开关一按：不加载、也不输出它的触发词                |
| 触发词靠手抄，漏一个就白跑            | 自动合并成一个字符串端口，直接接 `CLIP Text Encode` |

### 为什么强调「不碰 CLIP」

`LoraLoader` 会把 LoRA **同时**应用到模型和文本编码器。但对 2.5D / 动漫 / 写实类底模来说，很多时候你只想让 UNet 吃这个 LoRA，不想让它同时改变 CLIP 对提示词的理解——尤其是角色 LoRA，CLIP 被带偏后提示词会变得不好使。

本节点调用的是：

```python
comfy.sd.load_lora_for_models(model, None, lora_data, strength, 0.0)
#                                ^^^^ 第二个参数恒为 None —— 不动 CLIP
```

需要同时作用到 CLIP 的场合，建议直接用官方 `LoraLoader`；本节点的定位就是「只要 MODEL 那一半」。

## 两个版本

| 节点名                | 类名                       | 说明                                                           |
| ------------------ | ------------------------ | ------------------------------------------------------------ |
| **小岚lora阵列**       | `XiaoLanLoraArray`       | 纯 LoRA 阵列                                                    |
| **小岚lora阵列 + 提示词** | `XiaoLanLoraArrayPrompt` | 在左边基础上多：多行提示词框、可增删的**文本列表**、只读的**最终文本预览**、`文本输入` / `文本输出` 端口 |

两个节点在「加载 LoRA、合并触发词」上的逻辑是同一段代码（`_apply_rows()`），行为完全一致，只有文本部分不同。

## 安装

无第三方依赖，`git clone` 进去重启即可。

**方式一 · git（推荐，方便更新）**

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/<你的用户名>/ComfyUI-XiaoLan-LoraArray.git
```

**方式二 · 手动**

下载本仓库 ZIP，解压后把 `ComfyUI-XiaoLan-LoraArray` 整个文件夹放进 `ComfyUI/custom_nodes/`。

**方式三 · ComfyUI-Manager**

在 Manager 的 *Install via Git URL* 里粘贴本仓库地址。

装完**重启 ComfyUI**，在节点搜索里输入「小岚」即可找到，分类在 `loaders` 下。

### 更新时的一个顺序问题

> **先重启后端，再刷新页面。**

因为节点界面是前端 JS 注入的，而数据字段由后端定义。如果只强刷页面、后端还跑着旧 `nodes.py`，会看到控制台红字：

```
[小岚lora阵列] 后端缺少 rows_data / prompt_text / texts_data 输入，说明 ComfyUI 还在跑旧版 nodes.py
```

看到它就去重启 ComfyUI。反过来的情况（只重启后端没刷新页面）则强刷 **Ctrl + Shift + R** 即可。

> 小提示：如果某次更新**只动了前端 JS**，那连重启都不用，Ctrl + Shift + R 就够了。

## 用法

### 顶部一行

`[ 总开关 ] [ ＋ 添加 LoRA ]`（提示词版还多一个 `[ ＋ 添加文本 ]`）

- **总开关**：一键启停全部 LoRA。关闭时**模型原样透传，触发词一并清空**（提示词和文本列表不受影响）。
- **添加按钮固定在顶部**，不在节点底部——挂在底部的话每加一行它自己就往下跑，点完还得追着鼠标找它。
- 三个盒子各有各的热区，命中判定严格按 x 落在盒内、y 落在这一行内，**点缝隙不会误触发**。

### 每一行

```
[ 开关 ] [ ◀ LoRA 名称 ▶ ] [ － 权重 ＋ ] [ 触发词 ] [ ✕ ]
```

| 区域          | 操作                                                         |
| ----------- | ---------------------------------------------------------- |
| **开关**（最左）  | 单独启用/停用这一行。停用后**不加载 LoRA、不输出触发词**，行内容整体压暗便于辨认              |
| **LoRA 名称** | 点胶囊中间弹出下拉，**点一下即选中，无需输入文字**；菜单按文件夹分组，当前项打 ✓                |
| **◀ ▶ 箭头**  | 切换上一个 / 下一个 LoRA                                           |
| **权重**      | 点 `－` / `＋` 每次 ±0.05；**按住中间左右拖动**可按 0.01/像素 微调，范围 −10 ~ 10 |
| **触发词**     | 点击弹出输入框，`Enter` 保存、`Esc` 取消。只填触发词也是一条合法行                   |
| **✕**       | 删除该行，后面行整体上移。只剩一行时点 ✕ 是重置成空行，不会删成 0 行                      |

**行数不限**（安全上限 200）。超过 30 行时会多出一行灰色说明，原因见下方「关于 30 个端口」。

### 文本列表（仅提示词版）

- 点顶部 `＋ 添加文本` 增加一条，条数不限（上限 50）。**删光后整块自动收起，节点高度回落。**
- 每条一行：`[ 开关 ] [ 标题/备注 ] [ 正文 ] [ ✕ ]`
- **标题是虚线框，纯粹给自己看，不参与输出**；**正文**才会拼进合并文本。
- 点击标题或正文弹出输入框编辑；每条左侧开关可临时停用它。
- 说明行右侧有 `✕ 删除末条`，专门用来撤销"手滑多点了两下添加"。

### 提示词框 / 预览 / 分隔条（仅提示词版）

- **提示词框**：原生多行文本框，可换行可滚动，**节点拉高时高度全给它**。
- **最终文本预览**（右侧只读）：实时显示合并结果、总字数、本次生效的触发词。不用为了确认"触发词到底拼上没有"而先执行一次再挂个 Show Text。
- **分栏可以拖**：两个框中间有一条分隔条，**按住左右拖**即可调宽度比，**双击**恢复默认（58%）。比例存在节点属性里，**跟着工作流一起保存**。两侧都有最小宽度兜底，拖到头也不会把某侧挤没。

## 端口

**小岚lora阵列**

| 方向 | 名称               | 类型             |
| -- | ---------------- | -------------- |
| 输入 | `model`          | MODEL          |
| 输入 | `toggle`         | BOOLEAN（顶部总开关） |
| 输出 | `model`          | MODEL          |
| 输出 | `触发词合并输出`        | STRING         |
| 输出 | `触发词1` … `触发词30` | STRING × 30    |

**小岚lora阵列 + 提示词**

| 方向 | 名称               | 类型                                        |
| -- | ---------------- | ----------------------------------------- |
| 输入 | `model`          | MODEL                                     |
| 输入 | `toggle`         | BOOLEAN                                   |
| 输入 | `text_in`（可选）    | STRING，`forceInput`，接外部文本                 |
| 输出 | `model`          | MODEL                                     |
| 输出 | `文本触发词合并输出`      | STRING                                    |
| 输出 | `触发词1` … `触发词30` | STRING × 30                               |
| 输出 | `文本输出`           | STRING（内容与合并输出完全相同，只是多一个紧挨提示词框的出口，方便就近接线） |

### 文本合并顺序

```
文本触发词合并输出 = 文本输入 + 提示词框 + 文本列表各条正文 + 各已启用行的触发词
```

各部分会去掉首尾空白和多余逗号，空片段直接跳过，所以「没写提示词」或「没填触发词」都不会留下孤零零的逗号。

### 关于「不限行数」与「30 个独立端口」

ComfyUI 的输出端口必须在**节点注册时**固定，所以「每行一个独立输出」只能给到固定条数。

- **行数本身不受限制**：第 31 行起依旧会加载 LoRA、依旧并入合并输出，只是没有自己的单独端口。
- 独立端口数上限是 30（`MAX_OUTPUTS`），行数安全上限是 200（`MAX_ROWS`）。

## 常见问题

<details>

<summary><b>节点显示成一堆原生文本框怎么办？</b></summary>

说明浏览器里跑的是**旧版 JS**（ComfyUI 只在页面加载时拉取一次扩展）。

1. 按 **Ctrl + Shift + R** 强制刷新；还不行就关掉标签页重开 `http://127.0.0.1:8188`。
2. 按 **F12** 看控制台：
   - 蓝色 `[小岚lora阵列] 前端扩展已加载 v7.4` → 新前端已生效，节点会自动变成阵列界面（**旧节点也会自愈，不必删掉重建**）。
   - 红色 `后端缺少 rows_data / prompt_text / texts_data 输入…` → 前端是新的，但**后端还是旧代码，去重启 ComfyUI**。
   - 什么都没有 → 页面没加载到这份 JS，检查有没有 `Failed to load module` / `400` 之类的网络报错。

</details>

<details>

<summary><b>打开旧工作流，以前的行还在吗？</b></summary>

在。界面会自动把旧版的 `row_1..row_10` 数据迁移成新的行格式；没有文本列表的旧工作流也不会凭空多出条目。新增字段时也做了兼容处理，**旧工作流里已经写好的提示词不会丢**。

</details>

<details>

<summary><b>报「找不到 LoRA 文件」？</b></summary>

报错里会带上缺失的文件名，去 `ComfyUI/models/loras/` 下核对。注意本节点的 LoRA 路径显示只取文件名（basename），但实际加载走 ComfyUI 自己的 LoRA 目录扫描。

</details>

<details>

<summary><b>权重设成 0 会怎样？</b></summary>

该行**直接跳过加载**（不做一次无意义的加载），但它仍然算一条启用行，触发词照常输出。

</details>

<details>

<summary><b>分隔条拖不动 / 想恢复默认？</b></summary>

热区就在两个框之间的缝隙上（画布区域，不在输入框内），鼠标移上去会变成 `col-resize` 光标。**双击分隔条**即可恢复默认 58%。

</details>

## 兼容性

- 实测环境：**ComfyUI 0.20.1 + 前端 1.42.15**（秋叶整合包 aki v1.7）。
- 前端扩展通过 `WEB_DIRECTORY = "./web"` 提供，挂载在 `/extensions/ComfyUI-XiaoLan-LoraArray/js/lora_array.js`。
- 无 Python 第三方依赖，只用 ComfyUI 自带的 `folder_paths` / `comfy.sd` / `comfy.utils`。
- 面向新版前端（1.4x）做过适配，详见 [docs/技术笔记.md](docs/技术笔记.md)。

## 开发

核心文件：

```
ComfyUI-XiaoLan-LoraArray/
├── __init__.py            # 注册节点 + WEB_DIRECTORY
├── nodes.py               # 后端：两个节点类、行/文本解析、LoRA 套用
├── pyproject.toml         # 元信息（MIT）
├── web/js/lora_array.js   # 前端：全部界面逻辑（约 2700 行）
└── docs/
    ├── images/            # README 截图
    └── 技术笔记.md         # 实现细节与新版前端踩坑记录
```

界面几乎全部由 `web/js/lora_array.js` 手绘与接管：行控件、顶部按钮热区、LoRA 下拉、文本列表、可拖动分隔条都在这里。数据统一由隐藏控件 `rows_data` / `texts_data`（JSON 数组）承载，所以条数不受 `INPUT_TYPES` 固定槽位限制。

想改这个节点，**强烈建议先看 [docs/技术笔记.md](docs/技术笔记.md)**——里面记了 9 个新版前端上踩过的坑（正反馈撑爆节点、端口隐藏、悬停无事件、扩展静默失效等），能省掉大量重踩时间。
